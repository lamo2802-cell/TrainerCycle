Structured indoor training, built around your FTP.

## What it does

- Set your current FTP once — it's stored in the browser and used to convert every %FTP step to watts.
- Build workouts from steady steps or work/recovery interval sets, with a live intensity-zone chart.
- Import a structured workout straight from Tredict's `planned-workout` JSON — it converts steps, repeats, and %FTP/watt/HR targets into the same format as anything built by hand.
- Save, reload, and export workouts from a persistent library.

## Roadmap

Live Bluetooth control (reading power/cadence/HR from a trainer and pushing ERG targets from the workout steps) is next, as a separate standalone page — Web Bluetooth needs a top-level browser tab rather than an embedded view.
